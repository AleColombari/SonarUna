    Contatos de ajuda

    Quando a pessoa diz preciso de ajuda, o app oferece ligar para um destes números. Os telefones ficam só neste navegador: não vão para o GitHub nem para o mapa. Para testar, use o seu próprio número.

    Como usar

    Use o Google Chrome ou o Edge, em localhost, e permita o microfone. Toque no botão, responda às perguntas em voz alta e diga pronto a cada etapa concluída. Você pode falar por cima do app para responder antes de ele terminar. Diga a qualquer momento: repetir, voltar, recomeçar, ajuda ou parar. Diga preciso de ajuda para falar com um atendente ou com a segurança.
